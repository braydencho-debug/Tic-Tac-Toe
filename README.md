# Tic-Tac-Toe

Overview: My project, Tic-Tac-Toe, allows players to click on a 3x3 grid board to play tic tac toe. The players must alternate, like in the game, and text above the board notifies whose turn it is, if there is a winner and if there is a draw.

How to run it: To run the game you should run 'npm install' to install the dependencies and 'npm start' to bring up a local host to play the actual game.

Your contribution: I added a feature that leads that notifies players if there is a draw!
